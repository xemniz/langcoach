# LangCoach

Conversational AI language tutor for Android & iOS. BYO-key. On-device memory.

## Status

Early development. No releases yet.

## Stack

Kotlin Multiplatform · Compose Multiplatform · Room 3 · Ktor 3 · Koin 4 ·
AndroidX Navigation 3 · OpenAI Realtime API · Koog

## Project structure

See [`CLAUDE.md`](CLAUDE.md) for architecture and conventions.
See [`docs/design.md`](docs/design.md) for design history and reasoning.

## Building

Requires:

- JDK 17+
- Android Studio (Meerkat or newer) with the Kotlin Multiplatform plugin
- Xcode 16+ for iOS builds

```bash
./gradlew build
```
