# 05: Adapt teaching to the learner's ability

**What to build:** Adjust language, support, explanation, and task difficulty from complete beginner through advanced while keeping adult, meaningful lesson content.

**Blocked by:** 04: Teach one prepared lesson.

**Status:** completed

- [x] Unknown ability is distinct from assessed ability.
- [x] Beginners can receive modelling and familiar-language repair; stronger learners receive demanding communicative tasks.
- [x] Learner requests for easier, harder, slower, or more explanation influence the lesson.
